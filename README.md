# FIREWORKS 3D — VFX 2.0

A real-time, mobile-playable 3D fireworks experience built with Three.js and Vite. It renders a night city beside a reflective lake with procedural firework shapes, volumetric-style glow, bloom, depth of field, smoke, shockwaves, 3D audio, and a live show director.

## Run

```bash
npm install
npm run dev        # http://localhost:3002
npm run build      # production bundle in dist/
npm run preview    # serve the production build
```

## Play

- **Start Show** launches the active mode's show; **Pause/Resume** and **Replay** are beside it.
- Modes: **FREE**, **FESTIVAL**, **CINEMATIC**, **NIGHT CITY**, **LAKE**, **GALAXY**.
- Drag to orbit, pinch or scroll to zoom. Camera panel offers free, ground, and cinematic views.
- **CUSTOM SHOW** lets you add timed cues with shape and color, then play the sequence.
- **PHOTO** captures a PNG; **REC** records the canvas and soundtrack to WebM.
- **SETTINGS** exposes quality (auto/low/medium/high/ultra), bloom, slow motion, and sound.
- Keyboard: `Space` pause, `R` replay, `S` slow motion, `P` photo, `C` camera, `1`–`6` modes.

Quality scales automatically from measured frame rate. On capable hardware the target is 60/90/120 FPS depending on display refresh.
